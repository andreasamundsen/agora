AGORA PRIVATE BETA — BUILD 0.1.50
Prepared 19 November 2026

Thank you for trying this private beta. This note explains what you are receiving and the risks you should know before installing it.

WHAT THIS BUILD IS
Agora is a local debate harness for Windows x64. It turns a position into an argument map, supports reading and staging that map, exports it as Argdown, and can run a model-judged session.

This is a compiled, binary-only beta. Agora's source files and build scripts are not included. It is not an open-source or source-available release. The installed app contains compiled assets, a bundled server, and third-party dependency files, but no Agora source repository.

INSTALL
1. Verify the SHA-256 checksum supplied with the installer before running it.
2. Run Agora-Setup-0.1.50.exe.
3. Windows will warn that the publisher is unknown. This build is unsigned. Choose More info, then Run anyway only if the checksum matches and you trust the person who sent it.
4. The installer is per-user and does not require administrator rights.
5. To upgrade, close Agora and run a newer installer over it. To roll back, uninstall and run the previous installer.

FIRST RUN
Agora opens with two reference debates and works without a model key. The local scaffolder can make structural maps, but they are labelled as scaffolds and are not topic-specific. Connect a provider in Settings for real argument generation and judgment.

WHERE YOUR DATA LIVES
- Debates and settings: %APPDATA%\Agora\data
- App log: %APPDATA%\Agora\agora.log
- The app installs under %LOCALAPPDATA%\Programs\Agora
Uninstalling removes the application but leaves your debates and settings behind. Delete %APPDATA%\Agora if you want a complete reset.

NETWORK AND LOCAL SERVER
Agora starts its own local server on 127.0.0.1 on a random port. The desktop window connects only to that local server. There is no remote Agora account, proxy, cloud sync, or telemetry service.
When you connect a model, the motion, argument map, chat messages, and judgment context you submit are sent directly to the provider you configure. The provider's terms and retention policy apply. A local model such as LM Studio or Ollama keeps model work on your machine.
The only external link in the app is to Argdown's website, and it opens in your browser.
There is no auto-update. New builds must be installed manually.

API KEY
The provider API key is stored locally in plain JSON inside %APPDATA%\Agora\data\settings.json. Use a dedicated test key that you can rotate. Do not use a shared production key. Use Forget saved key in Settings before handing the machine to someone else.

KNOWN RISKS
- The installer is unsigned, so SmartScreen will warn and some antivirus tools may be cautious.
- The API key is not encrypted at rest.
- The local API has no authentication. It is bound to loopback and intended for a single-user machine; do not expose it to a network.
- The dependency audit currently reports high-severity transitive advisories in the Argdown parser stack. Treat imported files from untrusted sources with caution.
- Beta software may lose or corrupt data. Back up debates you care about.
- The app log contains local paths and your Windows username. Review and redact it before sharing.

# Agora documentation

Agora is a local debate harness: map a position as a graph, interrogate it, stage it, and judge it. The [README](../README.md) is the short landing page; these guides hold the detail.

## Guides

- **[Using Agora](using-agora.md)** — the library, Case and Thread views, editing, the chamber, Stage, and appearance.
- **[Judging](judging.md)** — local link assessments, the evidence bar, the weighted case, statuses, playback, progress, and saved judgments.
- **[Providers & models](providers.md)** — OpenAI, OpenRouter, DeepSeek, Claude, Gemini, thinking controls, and model settings.
- **[Development & architecture](development.md)** — Argdown interchange, source layout, the local API, tests, privacy, and known limits.
